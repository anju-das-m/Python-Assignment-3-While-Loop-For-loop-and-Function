## 📝 Assignment Questions

### 1. Number Guessing Game – While Loop

Developed a simple number guessing game using a while loop.

**Concepts used:**
- Random number generation using `random.randint()`
- While loop
- Conditional statements
- `break`, `continue`, and `else`

**Objective:** Allow the user to guess a randomly generated number between 1 and 10 within three attempts.

### 2. Multiplication Table Generator – For Loop

Created a multiplication table generator using a for loop and the range function.

**Concepts used:**
- For loop
- `range()` function
- User input
- Arithmetic operations
- Formatted output

**Objective:** Generate a multiplication table from 1 to 10 for a user-provided number.

### 3. BMI Calculator – Functions

Created a BMI calculator using a user-defined Python function.

**Concepts used:**
- Function definition
- Function parameters
- Return statement
- User input
- Mathematical operations

**Formula:**

BMI = Weight (kg) / Height (m)²

**Objective:** Calculate and display Body Mass Index using a reusable function.
